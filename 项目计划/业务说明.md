# AI 工作流项目业务说明文档

本文件旨在梳理 AI 工作流项目的核心业务价值、使用场景及产品规划，为后续生成 PPT 演示文稿提供结构化内容支持。

---

## 1. 产品定位与愿景

### 1.1 产品定义
**AI 工作流**是一款基于 ReactFlow 的可视化、低代码 AI 任务编排平台。它通过图形化界面，将复杂的 AI 模型调用、数据库操作、外部 API 集成及业务逻辑控制串联成自动化流程。

### 1.2 核心愿景
让 AI 能力触手可及，通过可视化的方式简化复杂业务流程的自动化构建，提升企业与个人的生产力。

---

## 2. 核心功能亮点 (PPT 重点展示)

- **可视化画布**: 基于 ReactFlow 的拖拽式操作，直观呈现业务流转。
- **全能节点库**: 
    - **AI 节点**: LLM 模型、知识库检索、文档提取。
    - **执行节点**: API 调用、SQL 查询、脚本执行、数据操作。
    - **控制节点**: 条件分支、并行分支、循环、延时。
    - **人机交互**: 审批、抄送、通知。
- **AI 辅助生成**: 输入一段话（Prompt），自动生成对应的工作流草图。
- **仿真运行机制**: 在正式部署前，实时模拟工作流执行过程，调试变量，查看日志。
- **灵活变量系统**: 全局变量、节点输出引用、系统变量，实现数据的无缝传递。

## 3. 典型应用场景 (PPT 核心章节)

### 3.1 场景一：智能客服与知识问答
*   **流程描述**: 接收用户问题 -> 文档提取器识别关键点 -> 检索企业私有知识库 -> LLM 结合知识库生成回答 -> 发送通知给用户。
*   **业务价值**: 24/7 自动响应，基于私有数据，回答准确且具备专业性。

### 3.2 场景二：自动化数据分析报告
*   **流程描述**: 定时触发 -> 执行 SQL 查询业务数据 -> 数据操作节点处理格式 -> LLM 生成分析总结 -> 通过 API 发送到飞书/钉钉。
*   **业务价值**: 消除重复劳动，实现报表自动化，并利用 AI 提供深度见解。

### 3.3 场景三：AI 辅助内容创作与发布
*   **流程描述**: 输入主题 -> LLM 生成大纲 -> 并行分支（LLM 生成正文 + AI 绘图 API）-> 审批节点（人工审核）-> 自动发布到社交平台。
*   **业务价值**: 提升创作效率，保持内容质量，缩短发布周期。

### 3.4 场景四：企业内部行政/财务流程
*   **流程描述**: 提交申请 -> 条件分支判断金额 -> 并行审批 -> SQL 记录状态 -> 邮件/短信通知。
*   **业务价值**: 规范化流程，透明化审批，提高跨部门协作效率。

## 4. 深度行业场景 (PPT 扩展章节)

### 4.1 金融保险：智能化理赔与风控
*   **流程描述**: 接收理赔申请图片 -> 文档提取器（OCR）识别发票明细 -> 知识库检索理赔条款 -> LLM 自动核算赔付金额 -> 并行分支（人工复核 + 风险评分 API）-> SQL 更新理赔状态。
*   **业务价值**: 缩短理赔周期，降低核算错误率，提升用户满意度。

### 4.2 电商零售：智能商品运营
*   **流程描述**: 监控竞争对手价格（API）-> 数据操作节点计算动态定价 -> LLM 生成针对性的营销卖点文稿 -> AI 绘图生成活动海报 -> 自动更新至电商后台。
*   **业务价值**: 实时响应市场变化，提升运营效率，增强商品竞争力。

### 4.3 医疗健康：病历摘要与诊后随访
*   **流程描述**: 提取电子病历关键信息 -> LLM 生成结构化病历摘要 -> 根据出院时间设置延时节点 -> 自动触发随访通知（短信/语音）-> 收集反馈并存入数据库。
*   **业务价值**: 减轻医护负担，提升患者诊后体验，实现数据闭环。

### 4.4 法律服务：合同审查与风险评估
*   **流程描述**: 上传合同文档 -> 提取关键条款 -> 检索法律法规知识库 -> LLM 识别潜在合规风险 -> 生成法律审查报告 -> 发送审批给资深律师。
*   **业务价值**: 降低法律合规风险，提升法务审查效率，确保合同标准化。

### 4.5 人力资源：智能招聘与人才漏斗
*   **流程描述**: 抓取简历数据 -> LLM 提取技能与经历 -> 自动匹配岗位要求（LLM）-> 条件分支（通过/不通过）-> 自动预约面试 -> 记录面试评价。
*   **业务价值**: 自动化筛选简历，缩短招聘周期，精准匹配人才。

## 5. 产品竞争优势

- **易用性**: 无需编程背景即可上手，降低 AI 应用门槛。
- **灵活性**: 强大的节点组合能力，支持几乎任何业务逻辑。
- **智能化**: AI 不仅仅是流程的一部分，更是流程的构建者（AI 生成工作流）。
- **可维护性**: 模块化设计，易于扩展新节点类型，支持版本化管理（规划中）。
