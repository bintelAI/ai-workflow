# 全局配置按钮实现计划

## 需求分析
- 在配置工作流按钮左侧添加一个全局配置按钮
- 点击按钮弹出全局变量配置弹窗
- 复用现有的 VariableConfigEditor 组件
- 实现全局变量配置，供应给所有节点使用

## 实现步骤

### 1. 添加全局变量状态管理
- 在 `useWorkflowStore.ts` 中添加全局变量状态
- 添加相关的 actions 来管理全局变量

### 2. 创建全局配置弹窗组件
- 创建 `GlobalConfigModal.tsx` 组件
- 复用现有的 `VariableConfigEditor` 组件
- 实现弹窗的显示/隐藏逻辑

### 3. 修改 WorkflowApp.tsx
- 在配置工作流按钮左侧添加全局配置按钮
- 实现按钮点击事件，打开全局配置弹窗

### 4. 修改 VariableBindModal
- 修改 `VariableBindModal.tsx`，使其能够显示全局配置的变量
- 确保全局变量可以被所有节点选择使用

### 5. 更新类型定义
- 在 `types.ts` 中添加全局变量相关的类型定义

## 详细实现

### 1. 添加全局变量状态管理
- 在 `useWorkflowStore.ts` 中添加 `globalVariables` 状态
- 添加 `setGlobalVariables` 和 `updateGlobalVariables` 方法

### 2. 创建 GlobalConfigModal 组件
- 参考 `SettingsModal.tsx` 的实现
- 集成 `VariableConfigEditor` 组件
- 实现弹窗的打开/关闭逻辑

### 3. 修改 WorkflowApp.tsx
- 在 header 中添加全局配置按钮
- 使用 `Lucide-React` 的 `Settings` 图标
- 添加点击事件，打开全局配置弹窗

### 4. 修改 VariableBindModal
- 在 `getStartNodeVariables` 函数中添加全局变量的获取逻辑
- 确保全局变量显示在变量选择列表中

### 5. 更新类型定义
- 在 `types.ts` 中添加 `GlobalConfig` 接口
- 扩展 `WorkflowStoreState` 接口，添加全局变量相关字段

## 技术要点
- 复用现有的 `VariableConfigEditor` 组件，确保代码复用性
- 使用 Zustand 管理全局变量状态
- 确保全局变量可以被所有节点访问和使用
- 保持 UI 风格一致，使用 Tailwind CSS 样式

## 预期效果
- 配置工作流按钮左侧出现全局配置按钮
- 点击按钮弹出全局变量配置弹窗
- 可以在弹窗中添加、编辑、删除全局变量
- 所有节点可以通过变量绑定弹窗选择使用全局变量
